## 🚀 Featured Projects

### 💰 DailySpend — Expense Tracking Application
A full-stack expense tracking application that helps users manage their daily expenses, recurring payments, and budgets.

- React frontend with Firebase Authentication
- Node.js and Express backend
- MongoDB Atlas for persistent data storage
- Redis caching with TTL and cache invalidation
- Docker-based containerization
- REST APIs with authenticated user-specific data

**Tech Stack:** React · Node.js · Express · Firebase · MongoDB · Redis · Docker

### 🤖 Multi-Agent Content Pipeline
An AI-powered content generation pipeline built using LangGraph and local language models.

- Multi-agent workflow using shared state
- Researcher, Writer, Editor, and Fact Checker agents
- Conditional revision loop between agents
- Input, research, and output guardrails
- Local LLM inference using Hugging Face models

**Tech Stack:** Python · LangGraph · Hugging Face · PyTorch

### 📚 RAG Chunking Evaluation
An experimental project evaluating different document chunking strategies for Retrieval-Augmented Generation.

- Fixed-size, Recursive, and Semantic chunking
- Vector storage using ChromaDB
- Retrieval pipeline with reranking
- Evaluation using a question-answer dataset
- Automated experimental report generation

**Tech Stack:** Python · LangChain · Hugging Face · ChromaDB

### 💬 Real-Time Chat Backend Application
A backend application designed to explore real-time communication and backend infrastructure.

- REST APIs using Django REST Framework
- JWT-based authentication
- PostgreSQL for persistent storage
- Redis and Django Channels for WebSocket communication
- Celery and Kafka for asynchronous processing and messaging concepts
- Docker-based development environment

**Tech Stack:** Python · Django · PostgreSQL · Redis · Django Channels · Celery · Kafka · Docker
